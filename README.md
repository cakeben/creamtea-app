# creamtea-app

An app to find UK cream tea spots, show a league table, and search by postcode.

## Features
- postcode search (postcodes.io)
- map (OpenStreetMap + Leaflet)
- league ranking based on a composite score from rating, review count, and distance

## Deploy
GitHub Pages deploys automatically from `.github/workflows/deploy-pages.yml`.

## Notes
This first version uses a seeded UK location dataset. You can later wire Google Places / additional review APIs for broader aggregation.
